Teacher’s guide

How to evaluate

  1. Enter your name. Use the same name each time to return to your saved evaluations.
  2. Choose a student by number and watch the video.
  3. Move all three sliders from 0 to 10: Acting, Singing, and Expression (clarity and personality).
  4. Optionally choose a suggested role, then select Save evaluation. The next student opens immediately while your evaluation saves. Keep this page open until all saves finish; use Retry saving if needed.
  5. Use Find unevaluated to find missed students, or use Back and the number menu to review your work. Choose Change beside your name to switch teachers.
